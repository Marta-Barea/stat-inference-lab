# Statistical Inference Lab

This repository contains practical assignments implemented in **R**, focused on the theoretical foundations and applied methods of statistical inference for biological and biomedical data analysis. The work covers probability models, estimation methods, confidence intervals, hypothesis testing, bootstrap techniques, and inferential procedures for both quantitative and categorical data.

The repository is organized into reports and supporting assets, combining statistical methodology, reproducible analysis, and technical documentation.

## Course Overview

The course introduces the core principles of statistical inference, emphasizing how to draw conclusions about populations from sampled data under uncertainty. Topics include:

- Probability theory and stochastic models
- Random variables and probability distributions
- Likelihood and parameter estimation
- Confidence intervals and bootstrap methods
- Statistical hypothesis testing
- Parametric and non-parametric tests
- Permutation methods and multiple testing correction
- Applied inferential statistics using R

The course combines theoretical foundations with computational implementation and reproducible statistical analysis workflows.
